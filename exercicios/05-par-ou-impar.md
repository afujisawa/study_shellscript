# Exercício 05 – Número par ou ímpar

**Nível:** 5 de 20

## Enunciado

Crie um script que receba um número como argumento e informe se ele é par ou ímpar, usando `if`.

**Dica:** um número é par quando o resto da divisão por 2 é zero (operador `%`).

## Execução

```bash
./paridade.sh 8
```

## Saída esperada

```
8 é par
```

Para o número 7, a saída deve ser `7 é ímpar`.
