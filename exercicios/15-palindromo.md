# Exercício 15 – Verificação de palíndromo

**Nível:** 15 de 20

## Enunciado

Crie um script que receba uma palavra como argumento e informe se ela é um palíndromo, ou seja, se lida de trás para frente é igual à original.

**Dica:** use o comando `rev` para inverter a string e compare o resultado com a original.

## Execução

```bash
./palindromo.sh arara
```

## Saída esperada

```
"arara" é um palíndromo.
```

Para `./palindromo.sh casa`, a saída deve ser `"casa" não é um palíndromo.`
