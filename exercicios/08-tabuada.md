# Exercício 08 – Tabuada

**Nível:** 8 de 20

## Enunciado

Crie um script que receba um número como argumento e exiba sua tabuada de 1 a 10.

## Execução

```bash
./tabuada.sh 3
```

## Saída esperada

```
3 x 1 = 3
3 x 2 = 6
3 x 3 = 9
3 x 4 = 12
3 x 5 = 15
3 x 6 = 18
3 x 7 = 21
3 x 8 = 24
3 x 9 = 27
3 x 10 = 30
```
