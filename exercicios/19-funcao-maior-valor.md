# Exercício 19 – Função para encontrar o maior valor

**Nível:** 19 de 20

## Enunciado

Crie uma função chamada `maior_valor` que receba uma lista de números como parâmetros e retorne o maior deles.

O script deve chamar a função com os números `4 19 7 25 11` e exibir o resultado.

**Dica:** dentro da função, use `$@` para acessar todos os parâmetros. Para "retornar" o valor, imprima-o com `echo` e capture a saída com `$(...)`.

## Execução

```bash
./maior_valor.sh
```

## Saída esperada

```
Maior valor da lista: 25
```
