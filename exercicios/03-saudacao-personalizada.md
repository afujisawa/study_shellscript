# Exercício 03 – Saudação personalizada

**Nível:** 3 de 20

## Enunciado

Crie um script que solicite o nome do usuário e exiba uma saudação com esse nome.

**Dica:** use o comando `read` para ler a entrada do teclado.

## Execução

```bash
./saudacao.sh
```

## Saída esperada (exemplo)

```
Digite seu nome: Maria
Olá, Maria! Seja bem-vinda.
```
