# Exercício 14 – Contagem de linhas e palavras

**Nível:** 14 de 20

## Enunciado

Crie um script que receba o nome de um arquivo como argumento e exiba o número de linhas e de palavras que ele contém.

Antes de contar, verifique se o arquivo existe. Caso contrário, exiba uma mensagem de erro e encerre o script.

**Dica:** o comando `wc` com as opções `-l` e `-w` faz essa contagem.

## Execução

```bash
./contagem.sh texto.txt
```

## Saída esperada (exemplo)

```
Arquivo: texto.txt
Linhas: 4
Palavras: 27
```
