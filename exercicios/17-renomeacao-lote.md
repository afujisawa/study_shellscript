# Exercício 17 – Renomeação em lote

**Nível:** 17 de 20

## Enunciado

Crie um script que percorra o diretório atual e renomeie todos os arquivos `.txt` para `.bak`, exibindo cada operação realizada.

Ao final, exiba a quantidade de arquivos renomeados. Se não houver nenhum arquivo `.txt`, informe isso ao usuário.

## Execução

```bash
./renomear.sh
```

## Saída esperada (exemplo)

```
Renomeando: notas.txt -> notas.bak
Renomeando: lista.txt -> lista.bak
Concluído: 2 arquivo(s) renomeado(s).
```
