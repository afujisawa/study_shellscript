# Exercício 13 – Listagem de arquivos `.txt`

**Nível:** 13 de 20

## Enunciado

Crie um script que percorra o diretório atual e liste, um por linha, todos os arquivos com extensão `.txt`. Ao final, exiba a contagem total.

**Dica:** use um laço `for` com o padrão `*.txt` e um contador.

## Execução

```bash
./listar_txt.sh
```

## Saída esperada (exemplo)

Considerando um diretório com `relatorio.txt`, `notas.txt` e `lista.txt`:

```
relatorio.txt
notas.txt
lista.txt
Total: 3 arquivo(s) .txt
```
