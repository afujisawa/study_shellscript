# Exercício 04 – Soma de dois argumentos

**Nível:** 4 de 20

## Enunciado

Crie um script que receba dois números como argumentos de linha de comando (`$1` e `$2`) e exiba a soma deles.

**Dica:** use a expansão aritmética `$(( ))` para realizar o cálculo.

## Execução

```bash
./soma.sh 7 5
```

## Saída esperada

```
A soma de 7 e 5 é 12
```
