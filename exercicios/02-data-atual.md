# Exercício 02 – Data e hora atual

**Nível:** 2 de 20

## Enunciado

Crie um script que exiba a mensagem `Hoje é` seguida da data atual no formato `DD/MM/AAAA`.

**Dica:** use o comando `date` com o formato adequado (`+%d/%m/%Y`) e armazene o resultado em uma variável.

## Execução

```bash
./data_atual.sh
```

## Saída esperada (exemplo)

```
Hoje é 18/10/2026
```
