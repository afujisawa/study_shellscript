# Exercício 06 – Verificação de arquivo

**Nível:** 6 de 20

## Enunciado

Crie um script que receba o nome de um arquivo como argumento e informe se ele existe no diretório atual.

**Dica:** o teste `-e` verifica se o caminho existe.

## Execução

```bash
./verifica.sh notas.txt
```

## Saída esperada

Se o arquivo existir:

```
O arquivo notas.txt existe.
```

Se o arquivo não existir:

```
O arquivo notas.txt não foi encontrado.
```
