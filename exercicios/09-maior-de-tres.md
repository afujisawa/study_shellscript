# Exercício 09 – Maior de três números

**Nível:** 9 de 20

## Enunciado

Crie um script que receba três números como argumentos e exiba qual é o maior.

**Dica:** use `if`, `elif` e `else` com os operadores de comparação numérica (`-gt`, `-ge`, etc.).

## Execução

```bash
./maior.sh 12 45 30
```

## Saída esperada

```
O maior número é 45
```
