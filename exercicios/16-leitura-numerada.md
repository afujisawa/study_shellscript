# Exercício 16 – Leitura numerada de arquivo

**Nível:** 16 de 20

## Enunciado

Crie um script que leia um arquivo linha por linha e exiba cada linha precedida do seu número.

**Dica:** use `while read -r linha` com um contador.

## Execução

```bash
./numera.sh poema.txt
```

## Conteúdo de `poema.txt`

```
Quem tem fé
vive em paz
```

## Saída esperada

```
1: Quem tem fé
2: vive em paz
```
